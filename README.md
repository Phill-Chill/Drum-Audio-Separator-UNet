# Guitar-Audio-Separator-UNet
Repositório acadêmico para separação e isolamento de faixas de guitarra utilizando arquitetura U-Net. Esta pesquisa serve como base e primeira etapa para o desenvolvimento futuro de um modelo de emulação neural de efeitos e amplificadores (Neural Amp Modeling).
